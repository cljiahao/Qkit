# assets

## Purpose

Optional royalty-free music bed(s) that `compose.mjs` mixes under the demo recording (low volume, faded in/out) — the demo works without one, playing only the synthesized "order ready" chime.

## Contents

- `pulsebox-lofi-smooth-522876.mp3` — a lofi background track; `compose.mjs`'s `findMusic()` picks it up automatically (it scans this folder for any `.mp3`/`.m4a`/`.wav`/`.ogg`/`.aac` file, preferring one literally named `music.*`, else the first match found — currently this file).
