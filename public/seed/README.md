# seed

## Purpose

Placeholder SVG menu-item images used by the demo/seed booth data (`supabase/seed/`), so seeded booths render real-looking menu photos without needing uploaded images.

## Contents

- `ice-cream-cart.svg` — placeholder booth/cart art for an ice-cream-cart-themed seed booth.
- `kopi.svg` — placeholder drink icon for kopi (coffee), used by the coffee-cart seed.
- `kopitiam-cart.svg` — placeholder booth/cart art for the "Kopitiam Cart" seed booth (the booth `e2e/customer-order.spec.ts` and `e2e/order-code.spec.ts` exercise).
- `milo.svg` — placeholder drink icon for Milo.
- `teh.svg` — placeholder drink icon for teh (tea).
