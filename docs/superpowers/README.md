# superpowers

## Purpose

Dated design specs and implementation plans produced by the brainstorm → design → plan workflow (the `superpowers` skill set) used to build every feature in this repo, so a feature's rationale and its step-by-step build history stay attached to the codebase.

## Contents

- `plans/` — one step-by-step implementation plan per feature (what got built, task-by-task).
- `specs/` — one approved design doc per feature (the problem, decisions, and architecture that plan was built from).

## Connectivity

`specs/` holds the approved design docs; `plans/` holds the corresponding step-by-step implementation plans generated from those specs — one pair per feature, matched by date and topic name (e.g. `2026-06-09-booth-menu-management-design.md` ↔ `2026-06-09-booth-menu-management.md`). `AGENTS.md` points to `docs/superpowers/plans/2026-06-05-qkit-core.md` as the plan of record for the original build.
