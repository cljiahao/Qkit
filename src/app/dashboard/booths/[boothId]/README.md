# [boothId]

## Purpose

Edit-booth page, keyed by booth id, plus its printable QR code sub-route.

## Contents

- `page.tsx`
- `qr/`

## Connectivity

`page.tsx` is the edit form (the shared `booth-form.tsx` pre-filled with this booth's data); `qr/` is the printable QR-code sub-route for this specific booth.
