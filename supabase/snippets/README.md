# snippets

## Purpose

Supabase Studio's saved-SQL-query folder — when a developer saves a query
from the local Studio UI (`http://127.0.0.1:54323`), the CLI writes it here so
it's available across `supabase start` sessions. It is not read or referenced
by the application, migrations, or tests.
